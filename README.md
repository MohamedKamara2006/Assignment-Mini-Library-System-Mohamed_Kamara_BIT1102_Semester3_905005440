How to Run the Mini Library Management System
Step 1: Make sure Python is installed
Check your Python version by running:
python --version
If Python is not installed, download it from: https://www.python.org/downloads/

Step 2: Open the project folder
Place all files in one folder:
operations.py
demo.py
tests.py

Step 3: Run the demo file
Open your terminal or command prompt in the folder and run:
python demo.py
This will:
Add sample books and members
Borrow and return a book
Show results in the terminal


Step 4: Run the test file

To check if everything works correctly, run:

python tests.py

If all is fine, you’ll see:

All tests passed successfully!
